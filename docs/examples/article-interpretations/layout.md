# 文章解读排版说明

- 标题层级使用 H1/H2/H3；正文 16px、1.8 行距，段落自然换行。
- Markdown 正文沿用阅读器 MarkdownRenderer；代码块横向滚动，公式保留原始字符。
- HTML 导出采用内联字体、行距、最大宽度和 `overflow-wrap:anywhere`，不引用图片、脚本、字体或 `file://` 资源。
- 来源发表日期与稿件生成日期分开显示；国内阅读链接直接使用 API 保存的 `china_article_url`。
- `method.html`、`case.html`、`research.html` 是本地浏览预览；微信编辑器粘贴效果未验证。
