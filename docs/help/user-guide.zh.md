# 用户指南

本指南介绍当前已提供的浏览、文件、知识库、Chat、账户和反馈功能。具体操作取决于账户权限和部署设置。

## 浏览与搜索 {#browse-search}

打开 **Database（数据库）** 浏览已收录文件。可以按标题、文件名或来源搜索，也可以用类别和来源筛选、排序及分页缩小范围。选择一行可打开文件详情。列表展示当前账户可访问的文件。

## 类别与来源 {#categories-sources}

打开 **Categories（类别）** 浏览文件当前使用的类别；打开 **Source Portals（来源门户）** 查看受监测的网站及其简介。类别页面可以跳转到匹配文件。如果存在该类别可用的就绪知识库，并且账户有 Chat 权限，页面可能显示 **Ask AI** 入口。

## 文件详情与阅读 {#file-details}

从 Database 打开文件，可查看标题、来源、类别、摘要、关键词及可用内容。本地文件存在时可以使用 **Preview（预览）**；只有权限允许时才会显示 **Download（下载）**。如果文件有 Markdown 内容，可以在详情页阅读。编辑目录信息、修改 Markdown、运行处理任务和删除文件都需要相应权限；没有权限时相关操作不会显示或不可用。

## 知识库与当前 Chat {#knowledge-chat}

打开 **Knowledge Bases（知识库）** 查看可用知识库及其就绪状态。拥有目录管理或任务权限的用户可能还会看到设置和处理操作。打开 **Chat**，选择可用知识库和回答模式后即可提问。类别页的 **Ask AI** 会在专用知识库就绪时带着该类别进入 Chat。回答可能包含来源文件引用。新的助手提问面板及其知识库问答功能尚未交付。

## 账户与额度 {#account-quota}

如果部署提供登录或注册入口，可以登录或注册。登录后打开 **Profile（个人资料）**，查看角色、Chat 额度使用量、剩余额度和近期活动。匿名访问者只能使用部署开放的公共功能。Chat 限额取决于部署和账户配置；如需确认额度，请联系管理员。

## 反馈入口 {#feedback-entry}

部署启用反馈后，可点击页面右下方浮动的 **Help and feedback（帮助与反馈）** 按钮，填写问题或建议并提交。关闭反馈功能时该入口会隐藏。提交成功后会显示回执；反馈不会作为 Chat 问题发送。当前小组件只接收反馈，不会回答使用问题。

## 常见问题处理 {#common-failures}

如果列表或文件未显示，请清除搜索词和筛选条件后重新加载。如果无法预览或查看 Markdown，文件可能没有本地副本或可读的 Markdown。知识库不可用时，可选择其他就绪知识库，或请管理员检查索引状态。Chat 提示额度已用完时，请等待额度周期重置或联系管理员。反馈无法提交时，请在服务恢复后重试；如果已显示回执，请保留回执信息。权限错误表示当前账户没有该操作权限。
