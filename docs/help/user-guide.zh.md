# 用户指南

本指南介绍当前已提供的浏览、文件、知识库、Chat、账户和反馈功能。具体操作取决于账户权限和部署设置。

## 功能与 Dashboard {#features-dashboard}

有哪些功能？怎么用？操作手册从这里开始：**Dashboard（首页，/）** 展示当前文件、目录、来源数量、进行中的任务，以及有快照时最近一期已发布周报的新增资料。**Database** 搜索文件，**Source Portals** 查看来源，**Categories** 浏览类别，**Knowledge Bases** 看索引状态，**Chat** 提问，**Weekly** 阅读周报，**Profile** 查看账户与额度，**Help and feedback** 查帮助或提建议。导航只显示当前账户有权限使用的入口。首页周报卡片的 **View all（查看全部）** 打开 **/weekly**。

## 浏览与搜索 {#browse-search}

打开 **Database（数据库）** 浏览已收录文件。可以用文本搜索查找文件，并用单独的类别和来源筛选、排序及分页缩小范围。选择一行可打开文件详情。列表展示当前账户可访问的文件。

## 类别与来源 {#categories-sources}

打开 **Categories（类别）** 浏览文件当前使用的类别；打开 **Source Portals（来源入口）** 浏览已整理的来源条目、简介和近期动态。部分条目为历史记录或已暂停。类别页面可以跳转到匹配文件。如果存在该类别可用的就绪知识库，并且账户有 Chat 权限，页面可能显示 **Ask AI** 入口。

## 周报使用 {#weekly-reports}

周报怎么用？本周新增在哪里看？从 Dashboard 首页周报卡片点击 **View all（查看全部）**，或直接打开 **/weekly**。页面先展示最近一期**完整已发布**快照，并不把尚未完成的本周当作已发布周报。可选择较早的已发布期数查看历史清单，点击其中资料阅读详情、原文链接，以及可用的预览或 Markdown。周报“新增”按该期资料的系统首次收录时间（`first_seen`）统计；已发布期数若为零项，表示按此口径没有新增。如果还没有完整已发布快照，页面会明确提示。可打开的操作入口是 **/weekly**。

## 日期与更新 {#dates-updates}

资料的发布日期（`files.published_time`）、系统首次收录时间（`files.first_seen`）和加入知识库时间（`rag_kb_files.added_at`）分别表示不同事件。Source Portals 的动态记录描述来源活动。目前没有记录内容修订血缘，因此 `last_seen`、定时刷新、HTTP 状态或单一当前哈希不能证明正文曾更新。请分别询问发布日期、最近收录或周报新增。

## 文件详情与阅读 {#file-details}

从 Database 打开文件，可查看标题、来源、类别、摘要、关键词及可用内容。本地文件存在时 **Preview（预览）** 按钮可用。**Download（下载）** 按钮始终显示，但只有本地文件存在且账户拥有下载权限时才可用。如果文件有 Markdown 内容，可以在详情页阅读。编辑目录信息、修改 Markdown、运行处理任务和删除文件都需要相应权限；没有权限时相关操作不会显示或不可用。

## 知识库与当前 Chat {#knowledge-chat}

打开 **Knowledge Bases（知识库）** 查看可用知识库及其就绪状态。拥有目录管理或任务权限的用户可能还会看到设置和处理操作。打开 **Chat**，选择可用知识库和回答模式后即可提问。类别页的 **Ask AI** 会在专用知识库就绪时带着该类别进入 Chat。回答可能包含来源文件引用。启用网站小助手后，可询问使用方法、查找公开目录与摘要，并读取服务端为当前身份开放的知识库。列表中能看到知识库不代表助手获准读取；内部知识库仅向已登录的操作员或管理员开放。目录摘要不能作为全文结论。知识库回答引用实际正文片段及当前服务版本，较早服务版本会标记；缺少证据或索引不可用时会明确说明。

## 账户与额度 {#account-quota}

如果部署提供登录或注册入口，可以登录或注册。登录后打开 **Profile（个人资料）**，查看角色、Chat 额度使用量、剩余额度和近期活动。匿名访问者只能使用部署开放的公共功能。Chat 与网站小助手共用每日 AI 额度：访客每天 5 次，注册用户每天 20 次，按 UTC 日期重置；其他角色沿用现有 Chat 额度。手动反馈和查阅帮助不调用 AI，也不占用该额度。

## 反馈入口 {#feedback-entry}

反馈与助手是独立开关，默认都关闭。任一功能开启时，右下方显示 **Help and feedback（帮助与反馈）** 入口。只启用反馈时，入口会直接打开普通可编辑表单；同时启用助手时，点击 **提建议** 可打开该表单，不调用 AI。检查正文后再提交，只有服务端返回回执才算成功。启用助手后，在唯一的问题输入框直接输入问题；助手会自动选择所需工具。用法回答附当前指南引用，点击引用可阅读对应的准确章节及版本；目录与知识库引用可打开文件详情。资料不足会明确说明。助手识别为反馈时，只将用户原文准备成可编辑草稿，取消不会提交。关闭反馈时不显示提交动作。每次提问相互独立；记录仅在本页展示，换页或刷新清空，不保存到 Chat。模型失败时仍可 **查阅使用帮助（不调用 AI）** 或手动提建议。

## 常见问题处理 {#common-failures}

如果列表或文件未显示，请清除搜索词和筛选条件后重新加载。如果无法预览或查看 Markdown，文件可能没有本地副本或可读的 Markdown。知识库不可用时，可选择其他就绪知识库，或请管理员检查索引状态。Chat 提示额度已用完时，请等待额度周期重置或联系管理员。反馈无法提交时，请在服务恢复后重试；如果已显示回执，请保留回执信息。权限错误表示当前账户没有该操作权限。
